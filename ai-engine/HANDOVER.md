# AI / ML Detection Engine – Handover Document

## Project Overview
This project implements a **Cloud-Based AI-Driven Self-Healing Web Application Firewall (WAF)**.  
The AI/ML Detection Engine is responsible for analyzing WAF and application logs, detecting anomalous or malicious traffic, and sending threat decisions to the self-healing automation layer.

---

## Module Ownership
**Owner:** AI / ML Detection Engine  
**Folder:** `ai-engine/`

This module does **not** modify WAF rules or infrastructure directly.  
It only **analyzes logs and outputs decisions**.

---

## Responsibilities
- Ingest WAF and application logs (file-based)
- Extract security-relevant features
- Apply Machine Learning model for anomaly detection
- Generate confidence scores
- Send detection results to the self-healing engine

---

## Log Ingestion
Logs are ingested from CSV files generated by the WAF/logging layer.

**Input File Example:**
import pandas as pd
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import MinMaxScaler
import json

# ==============================
# STEP 1: Load Dataset
# ==============================
DATASET_PATH = "waf_dataset.csv"

data = pd.read_csv(DATASET_PATH)

# ==============================
# STEP 2: Select Features
# ==============================
features = data[[
    "uri_length",
    "payload_length",
    "keyword_count"
]]

# ==============================
# STEP 3: Normalize Features
# ==============================
scaler = MinMaxScaler()
features_scaled = scaler.fit_transform(features)

# ==============================
# STEP 4: Train Isolation Forest
# ==============================
model = IsolationForest(
    n_estimators=100,
    contamination=0.1,
    random_state=42
)

model.fit(features_scaled)

# ==============================
# STEP 5: Predict Anomalies
# ==============================
predictions = model.predict(features_scaled)
anomaly_scores = model.decision_function(features_scaled)

# Convert predictions
# -1 → attack (1)
#  1 → normal (0)
data["attack"] = np.where(predictions == -1, 1, 0)

# Normalize confidence score (0–1)
data["confidence"] = np.abs(anomaly_scores)
data["confidence"] = data["confidence"] / data["confidence"].max()

# ==============================
# STEP 6: Generate Output for Self-Healing
# ==============================
alerts = []

for _, row in data.iterrows():
    if row["attack"] == 1:
        threat_level = (
            "HIGH" if row["confidence"] > 0.7 else
            "MEDIUM" if row["confidence"] > 0.4 else
            "LOW"
        )

        alerts.append({
            "ip": row["ip"],
            "threat_level": threat_level,
            "confidence": round(row["confidence"], 2),
            "recommended_action": "BLOCK" if threat_level == "HIGH" else "MONITOR"
        })

# ==============================
# STEP 7: Save Output
# ==============================
with open("ai_output.json", "w") as f:
    json.dump(alerts, f, indent=4)

print("✅ Detection completed")
print("🚨 Alerts generated:", len(alerts))
